Features

Everything you need.
Nothing you don't.

Designed for speed and simplicity — load a file, set your crop, export.

✂️

Precise Crop Overlay

Drag corners, edges, or the whole window. Aspect-locked resize keeps output clean. Rule-of-thirds grid for framing.

🎬

Frame-Perfect Trim

Range slider plus ±1 ms / ±100 ms / ±1 s buttons for IN and OUT points. Set IN or OUT at the current playback position.

🖼️

Image Cropping

Same crop overlay works on photos. Saved as JPEG to Pictures / Cropped — immediately visible in your gallery.

💾

Gallery-Ready Export

Videos land in Movies / Cropped, images in Pictures / Cropped. Uses MediaStore so files appear instantly.

⏱️

Default IN Time

Persist a default start time with millisecond precision. Every video you open begins at that offset automatically.

🪟

Transparent UI

50 % opacity panels let your wallpaper show through the entire app — header, preview, and controls all match.
